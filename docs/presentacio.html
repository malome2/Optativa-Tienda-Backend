Funcionalitats principals

🔐 Autenticació

  • Registre i login d'usuaris
  • JWT amb access token i refresh token
  • Control d'accés per rol (usuari / admin)

🛒 Botiga

  • Catàleg de jocs amb filtres i cerca
  • Cistella de la compra per usuari
  • Gestió de comandes i direccions

💳 Pagaments

  • Integració amb Stripe Checkout
  • Webhook per confirmar pagaments
  • Historial de comandes per usuari

📊 Administració

  • Dashboard d'admin protegit per rol
  • Gestió de productes i usuaris
  • Mètriques de servidor en temps real

Observabilitat

El backend genera informació estructurada per entendre què passa en temps real.

📋 Logs estructurats

Cada petició HTTP genera un log JSON amb mètode, URL, status i temps de resposta.

🔍 Request ID

Cada petició té un identificador únic (UUID) per traçar-la de principi a fi.

❤️ Health & Metrics

/api/health — estat de la BD.
/api/metrics — memòria i CPU (protegit per admin).
